#  Бронирование переговорной комнаты

Интерактивное клиентское веб-приложение для управления расписанием переговорной комнаты. Проект разработан в рамках лабораторной работы (Вариант 12) с использованием чистого JavaScript, без применения фреймворков и серверной части.

##  Возможности приложения

- **Управление датами:** навигация по дням (вперед/назад), быстрый переход к текущей дате, ручной выбор через календарь.
- **Визуальная сетка слотов:** отображение временных интервалов с 9:00 до 18:00 с шагом 30 минут.
- **Интерактивное бронирование:** создание записи через модальное окно или быстрый клик по свободному слоту.
- **Валидация данных:** проверка обязательных полей, корректности временного диапазона и отсутствие пересечений с существующими бронированиями.
- **Динамический интерфейс:** мгновенное обновление DOM при добавлении или отмене записи без перезагрузки страницы.
- **Визуальная обратная связь:** цветовая индикация состояний слотов (свободен/занят), всплывающие уведомления (toast) об успехе или ошибках.
- **Адаптивный дизайн:** корректное отображение на десктопах и мобильных устройствах.
